# Настройка сервера на Cloudflare — один раз, ~10 минут, бесплатно, без банковской карты

Это делает **только владелец лиги**. Пилоты и админы нигде не регистрируются:
пилот запускает exe, админ один раз вводит выданные ему логин и пароль.

Ливреи хранятся в Cloudflare. Ваши существующие ливреи и 3D-модели из GitHub-репозитория `dobeg-liveries`
остаются видны (только чтение), переносить ничего не нужно.

## 1. Аккаунт
https://dash.cloudflare.com/sign-up — только email и пароль.

## 2. Хранилище (KV)
**Storage & Databases → KV → Create** → имя `dobeg-liveries` → Create.

## 3. Worker
1. **Workers & Pages → Create → Create Worker** → имя `dobeg-livery-server` → **Deploy**.
2. **Edit code** → удалите всё → вставьте содержимое файла `worker/worker.js` → **Deploy**.

## 4. Привязка хранилища
Worker → **Settings → Bindings → Add → KV namespace**:
- Variable name: `LIVERIES` (точно так, заглавными)
- KV namespace: `dobeg-liveries` → Save / Deploy.

## 5. Логины админов
Worker → **Settings → Variables and Secrets → Add**:

| Тип | Имя | Значение |
|---|---|---|
| **Secret** | `ADMINS` | `kirill:длинный-пароль,ivan:другой-пароль` |
| Text | `OWNER` | `kirillkoltun0-ops` |
| Text | `REPO` | `dobeg-liveries` |

`ADMINS` — пары `логин:пароль` через запятую (можно кириллицу). Чтобы добавить или убрать админа — измените это значение,
пересборка приложения не нужна. `OWNER`/`REPO` — публичный репозиторий со старыми ливреями и папкой `models/`.
Необязательно: секрет `GH_TOKEN` — любой токен GitHub **без каких-либо прав** (нужен только чтобы GitHub не ограничивал чтение до 60 запросов/час).
Диагностика: `адрес/debug` показывает, прочитал ли Worker репозиторий GitHub и сколько файлов в KV.

## 6. Проверка
Откройте в браузере адрес Worker (`https://dobeg-livery-server.<аккаунт>.workers.dev`) — должно быть `{"ok":true,"kv":true}`.
Затем `адрес/tree` — JSON со списком файлов.

## 7. Адрес в приложение
Впишите адрес в `src/js/config.js` (`WORKER_URL`) и запустите сборку: GitHub → Actions → **Build Windows exe**.
(Для проверки без пересборки: Настройки → Синхронизация → «Адрес сервера».)

## Как этим пользоваться
- **Пилоты:** запустили exe — всё. Ливреи ставятся и обновляются сами.
- **Админ:** клик по профилю в шапке → логин и пароль (один раз, запоминается) → открывается «Админ-панель» → бросить папку с ливреей.
  Всё остальное (команда, кузов, превью, публикация) лаунчер делает сам.

## Лимиты бесплатного тарифа
100 000 запросов Worker и 100 000 чтений KV в день, 1 000 записей в день, 1 ГБ хранилища, файл до 25 МБ.
Для лиги этого хватает с запасом. Если Cloudflare недоступен, лаунчер читает старые данные из GitHub напрямую.
